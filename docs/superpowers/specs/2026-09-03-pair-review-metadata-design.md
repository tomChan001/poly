# 审核页时间与市场信息设计

## 目标

让审核人直接看到候选的关键时间和市场参数，不再需要从规则正文或外部链接猜测结算期限。

## 展示内容

在市场规则上方增加两个紧凑区域：

1. “关键时间”显示 Oddpool 候选更新时间、Kalshi 预计结算时间、Polymarket 预计结算时间和最晚可能结算时间。
2. “市场信息”显示来源编号、启用状态、最小下单数量、数量递增单位、两端市场类别、两端最小价格变化单位和审核人。

两端的买入方向继续显示在各自规则卡片中。状态名称使用中文，不再仅显示后台英文枚举。

## 时间规则

所有有效时间统一转换为北京时间，并在区域标题中说明。字段为空时显示“平台暂未提供”；无效时间显示“时间格式有误”，避免空白或误导性日期。

## 字段边界

前端类型补齐后台返回的完整市场对结构。`native_fingerprint` 和 `material_fingerprint` 仍纳入类型以防接口模型失真，但不在页面展示，因为内部哈希无法帮助普通用户作出审核判断。

## 验证

前端测试覆盖四个时间、北京时间转换、空时间提示、市场参数和中文状态。现有审核提交与草稿保护测试继续通过，并运行桌面端与手机端无溢出测试。
