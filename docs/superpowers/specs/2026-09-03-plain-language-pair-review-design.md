# 清晰易懂的市场对审核页设计

## 目标

让非技术用户能看懂审核页面在做什么、为什么十项都必须核对，以及每一项具体要比较什么。

## 页面表达

页面将用一句话说明：这里是在确认两个平台的合约是否描述同一件事，避免两个平台无法一赢一输。每个核对项保留真实的风控含义，但显示为“你需要看什么”和“为什么要看”的日常语言。原来的“互补真值表”和 `EXACT` 技术术语替换为简洁的结算结果说明和“确认可以配对”。

## 确认规则

十个勾选框继续作为安全门槛，因为任何一项差异都可能让两个市场无法互相对冲。页面会清楚告诉用户剩余多少项，并解释勾选代表“已经比较且确认一致”；十项全部完成后才能确认配对。拒绝候选的行为与后端接口保持不变。

## 边界与验证

不修改审核 API、已保存的数据结构、自动执行资格或风控机制。前端单元测试将验证未勾全时提示出现且确认按钮不可用，全部勾选后才可提交。
