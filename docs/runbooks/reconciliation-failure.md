# 对账失败处置

## 自动响应

余额、开放订单或成交任一差异都会原子关闭新开仓并发送高优先级告警。恢复进程可以继续查询已提交订单，
但不得创建新执行授权。

## 排查步骤

1. 保存 correlation ID、平台序列、REST 响应哈希和本地账本版本，禁止在原记录上覆盖修改。
2. 分别拉取两端可用余额、开放订单和近期成交，按平台 order/fill ID 去重。
3. 检查用户流断线窗口、乱序回报、未知响应查询结果和费用差异。
4. 将遗漏成交追加到本地账本；错误本地记录通过补偿事件修正，不删除审计事件。
5. 连续完成一次全量一致对账，并确认没有 `SUBMITTED` 或 `PARTIALLY_HEDGED` 遗留风险。

只有 operator 可按 kill switch runbook 恢复。人工审核的是异常证据与系统恢复，不是单笔订单。
