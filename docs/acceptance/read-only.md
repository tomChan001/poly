# Read-only 验收

- [ ] 连续 7 天无无法解释的订单簿序列缺口。
- [ ] 官方规则变化在一个采集周期内将相关 `EXACT` 映射置为 `STALE`。
- [ ] 100% 报价可用当时规则、订单簿、费用、余额和策略版本重放。
- [ ] 每个拒绝结果包含结构化原因。
- [ ] 每个拒绝结果包含规则、盘口、余额、手续费和风险策略证据版本。
- [ ] Google/Magic 连接测试的 create/post/cancel/update-allowance 计数均为 0。
- [ ] 缺失 venue capture time、超过 500ms 到达差或序列缺口均结构化拒绝。
- [ ] PostgreSQL 资金预留可跨进程恢复，且同一 correlation ID 的两腿保持原子与幂等。
- [ ] Oddpool 价格仅用于发现和证据展示，从不进入执行计算。
- [ ] 人工只审核合约等价性；系统没有逐笔交易批准接口。

任一证据缺失时不得进入 shadow 验收。

此清单只证明只读与模拟路径；不会发送真实订单，也不能替代未来单独批准的 live canary。
